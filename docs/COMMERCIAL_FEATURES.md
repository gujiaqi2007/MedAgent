# 健康守护 MedAgent · 商业化功能建议

> 目标：从「能跑通的 MVP」走向「可规模化的商用产品」。
> 以下按**优先级**与**领域**给出建议，并标注为什么重要、怎么落地。

---

## 一、合规与资质（P0，决定能不能卖）

| 事项 | 说明 | 备注 |
|---|---|---|
| 互联网医疗/健康管理资质 | 若涉及在线问诊、开方，需对应资质与医生执业备案 | 单纯健康管理可先做「健康教育 + 监测」 |
| 医疗器械属性界定 | 若对外宣称「诊断/筛查」，可能落入二/三类器械 | 建议明确「非诊断」，规避器械审批 |
| 数据合规 | 《个人信息保护法》《数据安全法》《健康医疗大数据管理办法》 | 知情同意、最小必要、可撤回、可删除 |
| 等保 / 数据出境 | 健康数据属敏感个人信息 | 三级等保、境内存储 |
| 电子处方与药事 | 对接药店/药企需处方流转资质 | 先做「医嘱建议」而非处方 |

## 二、临床安全（P0，决定敢不敢用）

1. **分诊规则医学审核与版本化**：规则表由医生/护士团队审核，每次变更留审计记录（谁、何时、改了什么）。
2. **高危症状强规则 + 人工复核**：胸痛、卒中、呼吸困难等「红标」不只依赖模型，命中即触发人工坐席或 120 流程。
3. **用药相互作用 / 禁忌检查**：开医嘱时校验过敏史、肾功能、合并用药（如华法林 + 阿司匹林）。
4. **跌倒 / 走失 / 长时间无活动检测**：结合手环加速度与地理围栏，异常自动通知监护人。
5. **急救闭环**：SOS → 监护人电话 → 未接升级 → 社区/120，全程留痕与回访。

## 三、产品功能（P1，决定好不好用、愿不愿意续费）

### 面向使用者（老人）
- **全双工语音 + 方言识别**（普通话/粤语/川渝等），降低使用门槛。
- **一键视频/图文问诊**（对接医生端），减少跑医院。
- **康复与运动指导**（关节操、呼吸训练），按病情推送。
- **心理关怀**：老年抑郁/孤独感筛查与陪伴式对话。

### 面向监护人
- **多患者/多监护人协作**：一个家庭多个老人、多个子女共同照护。
- **代际共享**：子女远程代录、代设提醒、代看报告。
- **异常解读**：不只报「异常」，而是「可能原因 + 现在该做什么」。
- **护理任务清单**：翻身、喂药、复诊预约等可勾选。

### 面向医生 / 机构
- **医生工作台**：批量患者、异常优先排序、随访计划。
- **电子病历 / HIS 对接**（FHIR），报告可直接进院。
- **慢病管理方案包**：高血压、糖尿病、COPD、心衰标准化路径。
- **家庭医生签约**：社区医院/养老机构 B 端。

### 硬件生态
- 血压计、血糖仪、体脂秤、血氧仪、跌倒检测雷达、智能药盒（提醒 + 记录）。
- 统一「设备接入网关」，支持华为/小米/苹果/Health Connect 多协议。

## 四、数据与 AI（P1，决定护城河）

1. **健康数据中台**：以 FHIR 标准化存储，支持导出给医院。
2. **个人健康画像 / 风险预测**：基于连续指标训练血压、血糖、跌倒风险模型。
3. **大模型 + RAG 可溯源**：回答引用指南来源，降低幻觉；敏感问题转人工。
4. **多模态**：语音、文本、图片（伤口/皮疹）、设备数据融合。
5. **模型评测体系**：构建「红/黄/绿」标准病例集，模型升级前回归测试。

## 五、商业与运营（P1/P2，决定赚不赚钱）

| 模式 | 说明 |
|---|---|
| 家庭订阅制 | 按月/年，含 1 位老人 + 多位监护人；增值包（专家咨询、报告解读） |
| 保险合作 | 健康险/慢病险按数据定价，降低理赔风险 |
| B 端（社区/养老院/医院） | 按床位/人头收费，提供管理后台 |
| 药企/器械合作 | 用药提醒、依从性数据、设备捆绑 |
| 增值服务 | 三甲专家图文/视频、体检套餐、营养师 |
| 24 小时护士/坐席 | 危急需人工介入，按次或包月 |

## 六、技术与安全（P1）

- **多租户 + 细粒度权限 + 审计日志**（谁看了谁的什么数据）。
- **端到端加密、密钥管理（KMS）、数据脱敏**。
- **高可用与灾备**：健康数据不可丢，定期备份 + 异地容灾。
- **可观测性**：告警送达率、AI 回答质量、设备在线率。
- **适老化认证**：大字体、高对比、语音优先，通过无障碍测评。

---

## 七、增长与获客（P2）

- 医院/社区/药店导流，子女「代付代管」降低决策门槛。
- 健康科普内容 + 名医背书，建立信任。
- 适老化认证 / 政府养老项目合作。

---

## 八、风险与伦理（P0，必须提前想清楚）

- **AI 误判责任**：明确免责边界，购买医疗责任/产品责任险，建立人工兜底。
- **数字鸿沟**：保留电话/线下通道，不让不会用手机的老人被排除。
- **过度医疗与数据滥用**：限制推送频率，数据用途透明。
- **伦理审查**：涉及老人的研究/算法训练需伦理委员会通过。

---

## 九、落地优先级建议

| 优先级 | 事项 |
|---|---|
| **P0（先做）** | 合规资质、分诊规则医学审核、急救闭环、数据加密与授权、免责与人工兜底 |
| **P1（3–6 个月）** | 多患者/多监护人、医生工作台、FHIR 对接、慢病方案包、订阅制 |
| **P2（6–12 个月）** | 风险预测模型、硬件生态、保险/药企合作、B 端机构版 |
