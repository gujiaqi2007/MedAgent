# MedAgent 健康守护 · 代码运行说明

> 适用版本：GitHub main 分支（2026-11-08 之后） ｜ 访问地址：http://127.0.0.1:8000

## 一、环境要求

- Python 3.10 及以上（推荐 3.12）
- 不需要安装数据库，数据保存在本机 SQLite
- 依赖：starlette、uvicorn、pydantic（见 requirements.txt）
- 操作系统：Windows / macOS / Linux 均可

## 二、获取代码

方式一（推荐，便于后续更新）：

```bash
git clone https://github.com/gujiaqi2007/MedAgent.git
cd MedAgent
```

方式二：在 GitHub 页面点击「Code → Download ZIP」，解压后进入 `MedAgent-main` 目录。

## 三、安装依赖

```bash
python -m pip install -r requirements.txt
```

国内网络较慢时使用镜像：

```bash
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 四、启动

Windows：双击 `run.bat`（会自动安装依赖并打开浏览器）。

或手动执行：

```bash
python -m app.main
```

然后在浏览器打开：http://127.0.0.1:8000

## 六、AI API Key 填写位置（重点）

AI 是**可选增强**：不填也能完整运行（纯本地规则、离线可用）；填写后回答更自然、更有共情。

### 方式一（推荐）：项目根目录 `.env` 文件

在项目根目录（与 `run.bat` 同一层）新建文件 `.env`，写入：

```ini
DEEPSEEK_API_KEY=sk-你的key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
```

保存后**重启服务**即生效。`.env` 已被 `.gitignore` 忽略，不会提交到仓库。

### 方式二：直接修改代码

打开 **`app/config.py`**，找到「AI 接入配置」这一段，把默认值改成你的 Key：

```python
DEEPSEEK_API_KEY = os.environ.get("DEEPSEEK_API_KEY", "")
DEEPSEEK_BASE_URL = os.environ.get("DEEPSEEK_BASE_URL", "https://api.deepseek.com")
DEEPSEEK_MODEL = os.environ.get("DEEPSEEK_MODEL", "deepseek-chat")
```

### 补充说明

- 支持任意 OpenAI 兼容服务（DeepSeek、SiliconFlow、OpenAI 等），只需修改 `DEEPSEEK_BASE_URL` 与 `DEEPSEEK_MODEL`。
- 调用逻辑在 `app/llm.py`；风险级别、是否拨打 120、是否通知监护人始终由本地规则决定，AI 只改写措辞。
- 确认是否生效：页面会显示「当前模式：AI 增强」；也可访问 http://127.0.0.1:8000/api/ai/status 查看。

## 七、常见问题

1. 端口被占用：换端口启动。

```powershell
$env:MEDAGENT_PORT=8001
python -m app.main
```

然后访问 http://127.0.0.1:8001。

2. 提示 `No module named 'starlette'`：依赖未安装，执行第三步。

3. 页面没有样式、一直停在「正在进入」：按 `Ctrl + F5` 强制刷新；确认地址是 `http://127.0.0.1:8000`，不要直接双击 HTML 文件。

4. 登录提示账号或密码错误：确认是首次启动（会自动建账号），或手动执行 `/api/seed`；确认输入的是 `zhang` / `123456`。

5. 语音不能用：使用 Chrome 或 Edge 浏览器，语音识别需要联网。

6. 页面打不开：确认命令行窗口仍然打开（关闭窗口即停止服务）。

## 九、提交与打包注意事项

以下内容不需要提交，已在 `.gitignore` 中排除：

- `data/`：本地数据库（首次运行自动生成）
- `dist/`、`build/`、`*.spec`：打包产物
- `.env`：含 API Key，切勿提交
- `__pycache__/`：Python 缓存

如需打包成 exe，可参考 README 中的 PyInstaller 命令。
