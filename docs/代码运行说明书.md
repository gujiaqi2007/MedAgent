## 一、概述

本说明书用于指导评审专家及使用人员在本机完成"健康守护 MedAgent"系统的部署、启动与验证。

系统采用前后端一体化架构：后端基于 Python 语言与 Starlette 框架实现，数据存储于本机 SQLite 数据库，无需额外安装数据库服务；前端为适配多端的网页界面。系统启动后通过浏览器访问，默认地址为 http://127.0.0.1:8000。

## 二、运行环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10/11、macOS 或 Linux |
| Python | 3.10 及以上，推荐 3.12 |
| 依赖库 | starlette、uvicorn、pydantic（详见 requirements.txt） |
| 数据库 | SQLite，随程序自动创建，无需单独安装 |
| 网络 | 本地运行不依赖网络；语音识别与 AI 增强功能需联网 |

## 三、获取源代码

### 3.1 方式一：Git 克隆（推荐）

```bash
git clone https://github.com/gujiaqi2007/MedAgent.git
cd MedAgent
```

### 3.2 方式二：下载压缩包

在 GitHub 仓库页面选择「Code → Download ZIP」，解压后进入解压目录。

## 四、安装依赖

在项目根目录执行以下命令：

```bash
python -m pip install -r requirements.txt
```

如网络访问较慢，可使用国内镜像源：

```bash
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 五、启动系统

### 5.1 Windows 环境

双击项目根目录下的 `run.bat`，程序将自动检查依赖、启动服务并打开浏览器。

### 5.2 命令行启动

```bash
python -m app.main
```

服务启动后，终端将显示访问地址与自检地址。请在浏览器中访问：

http://127.0.0.1:8000

### 5.3 更换端口（可选）

若默认端口 8000 已被占用，可通过环境变量指定其他端口：

```powershell
$env:MEDAGENT_PORT=8001
python -m app.main
```

随后访问 http://127.0.0.1:8001。

## 七、AI 服务配置说明

### 7.1 配置原则

AI 服务为可选增强功能。未配置时，系统以本地规则库独立运行，全部功能可正常使用；配置后，系统在保持本地规则判定的前提下，由大模型优化回答措辞。

无论是否配置 AI，风险等级判定、是否建议拨打 120、是否通知监护人，均由本地规则库决定，不受大模型影响。

### 7.2 配置方式一：使用 .env 文件（推荐）

在项目根目录（与 run.bat 同级）新建名为 `.env` 的文件，写入以下内容：

```ini
DEEPSEEK_API_KEY=sk-您的密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
```

保存后重新启动服务即可生效。该文件已被 .gitignore 排除，不会提交至代码仓库。

### 7.3 配置方式二：修改配置文件

打开 `app/config.py`，在「AI 接入配置」区域修改下列配置项：

```python
DEEPSEEK_API_KEY = os.environ.get("DEEPSEEK_API_KEY", "")
DEEPSEEK_BASE_URL = os.environ.get("DEEPSEEK_BASE_URL", "https://api.deepseek.com")
DEEPSEEK_MODEL = os.environ.get("DEEPSEEK_MODEL", "deepseek-chat")
```

### 7.4 配置项说明

| 配置项 | 说明 | 示例 |
|---|---|---|
| DEEPSEEK_API_KEY | 服务商提供的 API 密钥 | sk-xxxxxxxx |
| DEEPSEEK_BASE_URL | 接口地址，支持任意 OpenAI 兼容服务 | https://api.deepseek.com |
| DEEPSEEK_MODEL | 模型名称 | deepseek-chat |

### 7.5 生效验证

配置完成后重新启动服务，页面将显示「当前模式：AI 增强」；亦可访问以下地址确认：

http://127.0.0.1:8000/api/ai/status

## 八、常见问题处理

| 现象 | 可能原因 | 处理方式 |
|---|---|---|
| 端口被占用 | 8000 端口已被其他程序使用 | 按 5.3 节更换端口启动 |
| 提示 No module named 'starlette' | 依赖库未安装 | 按第四章安装依赖 |
| 页面无样式或停留在「正在进入」 | 浏览器缓存了旧静态资源 | 按 Ctrl + F5 强制刷新，并确认访问地址正确 |
| 登录提示账号或密码错误 | 数据库尚未初始化 | 按 6.2 节手动初始化 |
| 语音功能不可用 | 浏览器不支持或网络异常 | 使用 Chrome 或 Edge 浏览器，并保持联网 |
| 页面无法打开 | 服务进程已退出 | 确认命令行窗口处于运行状态 |

## 十、注意事项

1. 数据库文件位于 data/ 目录，首次运行时自动生成，请勿手动删除。
2. API 密钥属于敏感信息，请勿写入代码或提交至代码仓库。
3. 以下内容已在 .gitignore 中排除，无需提交：data/、dist/、build/、*.spec、.env、__pycache__/。
4. 语音识别依赖浏览器 Web Speech API，建议使用 Chrome 或 Edge 浏览器，并保持联网。
